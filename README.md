# Taylor Phillips — DPT Portfolio

Multi-page React portfolio with a professional medical theme.

## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build & deploy

```bash
npm run build
npm run preview
```

Deploy the `dist/` folder to Vercel, Netlify, or GitHub Pages.

## Customize

- Update text in `src/App.jsx`.
- Replace hero image in `src/App.jsx` or add your own in `src/assets/hero.jpg` and change the `src`.
- Colors/theme live in the background layer inside `SiteBackground`.

## Tests

```bash
npm run test
```

Vitest covers hash routing helpers and PAGES config.
